📚 使用示例

在 VS Code 中使用：

{
  "$schema": "https://REPO_OWNER.github.io/REPO_NAME/sing-box-config-schema.json"
}

使用方法

在你的 sing-box 配置文件中添加 $schema 字段：

{
  "$schema": "https://REPO_OWNER.github.io/REPO_NAME/sing-box-config-schema.json",
  "log": {
    "level": "info"
  },
  ...
}
